# sc-runtime v0.1.0

Core release of the four library crates and the cargo-generate template. The tag is the commit that carries this tree. Publication to crates.io and the GitHub Release are the sc-publish kit's `release.yml` dispatch, which still needs release authorization and registry credentials.

## Shipped

- Workspace members are exactly `sc-config`, `sc-transport`, `sc-command`, and `sc-runtime`, each at version 0.1.0, MIT licensed, with its own `README.md` and `LICENSE`.
- Publish order is the three leaves, then `sc-runtime`.
- `template/` renders a project whose dependencies on those four crates are crates.io version requirements (`0.1.0`). Release mode (`just new <dest> --var-file <fixture> --release`, or `SC_RUNTIME_RELEASE=1`) leaves those requirements in place and does not write `[patch.crates-io]`, a `path` dependency, or a `git` dependency for the four crates.
- Supported generation path: `just new <dest> --var-file wizard/fixtures/<fixture>.json` for every file in `wizard/fixtures/` (`sqlite-mcp.json`, `sqlite-no-mcp.json`, `sqlite-apache.json`). The driver then runs `just setup`, `just lint`, `just test`, `just build-cli`, and `just build-daemon`.
- Tag runs of `.github/workflows/template.yml` select that release mode. Pull-request runs still patch the checkout so template CI builds the crates at the same commit.
- Release workflows and `release/publish-*.toml` come from sc-publish `install.py`. The pin is `release/sc-publish-pin.toml`. Hand-authored publish workflows are forbidden. See [ADR-RUN-0002](../architecture.md).
- The GitHub Release for tag `v0.1.0` includes the workspace source archive `sc-runtime-{version}-source.tar.gz` from the kit's linux `release_targets` row. `release_binaries` is empty. Phase A ships no release binaries.
- `examples/spike/` is absent. Spike evidence stays in `docs/`.

## Deferred

These layers stay open. This release records them as deferred and does not schedule them.

- **CLI auto-start** ([REQ-RUN-0206](../requirements.md)). The CLI reports `DAEMON.NOT_RUNNING` when the daemon is unreachable. An optional auto-start layer is a later decision.
- **Attribute-generated CLI tests** ([REQ-RUN-0312](../requirements.md)). The two-pure-function helper and an attribute test framework are decision history, not part of this tag. The template still proves the example operation through the daemon fixture.
- **Wyvern wizard** (sprint a-8). `wizard/answers.schema.json` and `wizard/fixtures/` are in this tag. `wizard/wizard.json`, `wizard/pages/`, and `scripts/run_wizard.py` are the wizard milestone.
- **Minimum Cargo version.** The workspace `rust-version` is 1.94.1, and release preflight uses that toolchain. A minimum Cargo version beyond that toolchain is still open ([REQ-RUN-0002](../requirements.md)).
- Application-policy layers the requirements already mark deferred stay deferred. This tag does not close them.

## Generate

```bash
just new "$dest" --var-file wizard/fixtures/sqlite-mcp.json --release
```

Development checkouts omit `--release` so the generated project builds against `crates/` in this repository.
