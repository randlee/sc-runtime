Methodology

  • Timed iterations: 30 measured runs per case, each preceded by 1 untimed warmup (31 executions of the workload per case).
  • Wall clock: Rust Instant over the timed block only (warmup excluded).
  • Subprocess RSS: macOS /usr/bin/time -l on a separate one-shot command (isolates child peak).
  • Monty in-process RSS: getrusage(RUSAGE_SELF) after the timed Monty block—includes the test binary and Monty VM, not a standalone daemon.
  • Why Monty had no RSS earlier: the harness only attached time -l to subprocess cases; the Monty path runs inside cargo test until we added in-process getrusage and documented the compose child peak separately.

    progress = match progress {
        ReplProgress::FunctionCall(call) if call.function_name == "render_template" => {
            let template = call.args.arg(0)?.as_str()?;
            let rendered = run_sc_compose(template, context); // host spawns the CLI
            call.resume(ExtFunctionResult::Return(MontyObject::string(rendered)),
                        PrintWriter::Disabled)?
        }
        ReplProgress::Complete { .. } => break,
        _ => return Err(denied()),
    };
}
