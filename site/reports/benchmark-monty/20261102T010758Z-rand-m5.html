MEASURED means complete execution with one or more unratified (null) numerical ceilings; it is not a numerical performance PASS.

Methodology

Release-profile Rust harness. Each case has one untimed warmup before its recorded timed iterations. Wall-clock measurements use Rust Instant over the timed block only.

Subprocess RSS uses a separate one-shot macOS /usr/bin/time -l invocation. In-process RSS is getrusage(RUSAGE_SELF) high-water after the timed block and includes the test binary and Monty VM; it is not an isolated daemon measurement. Per-case memory notes identify the measurement method.

let mut progress = repl.feed_start(snippet, inputs, PrintWriter::Disabled)?;
loop {
    progress = match progress {
        ReplProgress::FunctionCall(call) if call.function_name == "render_template" => {
            let template = call.args.arg(0)?.as_str()?;
            let rendered = run_sc_compose(template, context); // host spawns the CLI
            call.resume(ExtFunctionResult::Return(MontyObject::string(rendered)),
                        PrintWriter::Disabled)?
        }
        ReplProgress::Complete { .. } => break,
        _ => return Err(denied()),
    };
}
